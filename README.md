# Personal Expense Tracker 💰

A full-stack web application to track your daily expenses, built with **Python**, **Flask**, and **SQLite**.

## Features

- Add expenses with amount, category, and description
- View all expenses in a clean, responsive table
- See total spent at a glance
- Data persisted in a local SQLite database
- Beautiful UI with Bootstrap 5

## Tech Stack

- **Backend:** Flask
- **Database:** SQLite (via `sqlite3`)
- **Frontend:** HTML5, Bootstrap 5, custom CSS
- **Language:** Python 3.x
